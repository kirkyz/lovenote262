Drainer Stage 5 ornaments

1. Extract this ZIP somewhere outside your project, e.g. Downloads.
2. Open Git Bash in the client project folder.
3. Run: bash /c/Users/Lkirk/Downloads/drainer_stage5_install/install_stage5.sh
   (Adjust path to the folder where you extracted this ZIP.)
4. The script backs up the existing screen, copies the updated screen and PNGs, then runs compileJava and build.
5. Test in Prism Launcher. Stage 5 decorations appear only in Premium style.

If the script reports an error, paste the compiler output.
